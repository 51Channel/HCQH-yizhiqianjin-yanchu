# 赫朝一掷千金游戏 · 演出审查包

《赫朝一掷千金游戏》是赫朝的 Minecraft 企划：30 个人进场，六场游戏一场一场打，只有 1 个能通关。
这个仓库只放**开场片头和规则演示**的东西，给外面的人（包括 AI）读、挑毛病。玩法代码不在这里。

## 请你做什么

1. 先读 **[演出观感.md](演出观感.md)**：这一期的画面和讲解该是什么样，主播历次的原话都在里面。
2. 对照它，把开场片头、游戏目标、六段规则演示从头到尾挑一遍毛病：讲解顺序、每一屏说的话、镜头、画面里演的事。
3. 按 `演出观感.md` 最后「怎么报问题」的表格格式列出来。**只找问题、给建议，不用改代码。**
4. 纯文案的改法也列进去：写清编号（[文案.md](文案.md) 里的 0- / Y-）、原文、改成什么、为什么。
5. **现在最想要的是视听建议**：读 [视听方案.md](视听方案.md)，给每个场景的音效、配乐、转场方案（格式在它第六节）。
